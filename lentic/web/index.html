Pictures

Ridges run up and down. Tip the plate left or right to switch pictures.

Drag each frame to choose the part that prints. The frame matches the plate, so nothing else gets cut off. Flip horizontal or Flip vertical if a picture came in the wrong way. The front picture is optional and sits on the flat top of each ridge.

Part size

Editing width or height updates the other. A picture sets the proportion.

Resolution

Each column is one ridge and each row is one band along it. A larger plate keeps this pitch, so 300 mm across holds far more of the picture than 80 mm. A 0.4 mm nozzle starts at 0.8 mm pitch and 0.4 mm rows. Raise the pitch toward 1.6 mm if a slope comes out too thin.

Color

One 3MF file. One part per color, already assembled, so the slicer can print each color as its own filament.

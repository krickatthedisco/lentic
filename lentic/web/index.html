Part size

The crop frame uses this shape. Match picture follows the first picture. Free lets you set width and height separately.

Setting this to 0 will allow you to glue the magnets in from the back after the print is complete instead of pausing the print and inserting them.

The base is the plastic below the magnets, plus the magnet, plus the plastic above them. Pause when the pocket is full, drop the magnets in, then let the print cover them. Each hole is 0.4 mm larger so the magnet drops in. Show magnet locations draws those pockets through the plate.

A raised lip is as thick as the whole plate, up to the ridge tips. A bevel slopes down toward the outside. A groove is a curved channel in the top of the frame. Rounded corners follow the outside. A tall lip can block the view at the very edge.

String holes run at 45 degrees through each top corner, from the top edge out the side, centered this far below the top.

The pocket opens on the back. The screw head drops into the round hole, then the frame slides down and the head catches in the wider space at the top.

A crest line can hide the appearance of the left image when viewing the right and vice versa, at the cost of introducing vertical banding across the image. Use whichever you prefer.

Resolution

Selecting your nozzle size automatically sets the default values to match, further adjustments may still improve image quality so play around with the values

Use the same layer height and first layer height as the slicer. The crest line is one layer tall and is placed on its own layer, above the pictures.

Each column is one ridge and each row is one band along it. A larger plate keeps this pitch, so it holds more of the picture. This plate uses a 1.6 mm pitch, a 1.28 mm ridge, and 0.4 mm rows. Each slope is 2 lines of the 0.4 mm nozzle. The tip is cut flat 0.5 mm in from each side. Layers are 0.2 mm after a 0.2 mm first layer. The crest line, if you turn it on, is 0.4 mm wide and 0.2 mm tall.

Color

Leave this off and Lentic chooses the colors. Turn it on to print with the filaments you actually have.

One 3MF file. One part per color, already assembled, so the slicer can print each color as its own filament. Lay the plate flat with the ridges facing up. Do not stand it on its side. Always print at 100% infill.
